npm install

2. Environment Configuration (.env.local)

GEMINI_API_KEY=your_key_here
STRIPE_SECRET_KEY=sk_live_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...

3. Run Locally & Deploy

npm run dev

Open http://localhost:3000 for landing page or /dashboard for the interactive playground. Ready for 1-click Vercel deployment.

Gemini 2.5 B2B Document & Invoice Extractor

Autonomous multimodal parser that extracts invoice numbers, dates, line items, VAT, and IBAN into validated Pydantic JSON with zero external OCR engines.

1. Install Requirements

pip install -r requirements.txt

2. Run via CLI or Web UI

# CLI execution:
python parser.py sample_invoice.pdf

# Start drag-and-drop web UI:
python app.py

Open http://localhost:8000 to drag and drop PDF and image invoices directly in your browser.
